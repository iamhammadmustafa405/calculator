# Mathemagic Calculator

A scientific calculator, calculus solver, statistics tool and function grapher in your browser.

**Try it live:** https://iamhammadmustafa405.github.io/calculator/

## Features
- **Scientific:** sin, cos, tan, log, ln, √, powers, factorial, DEG/RAD, and a history list
- **Calculus ∫:** derivatives and integrals of any function you type
- **Statistics σ:** mean, median, mode, standard deviation and regression
- **Graph 📈:** plot up to 6 functions; drag, zoom and hover to read values
- **Live 〰️:** animated graphs that move over time, like `sin(x - t)`
- Voice 🎤, screenshot 📷 and handwriting ✍️ input
- Google sign-in, your name, and Black / Blue / White themes
